# 画面ごとの、実装済みの機能の一覧（デザインの作り直し用）

2026-10-13 時点の、**実際のコードから起こした**一覧。`design-handoff.md` とあわせて渡す。
デザインは、**ここに書かれた機能が、すべて、画面に存在する前提**で作ってほしい。見た目・配置・文言のトーンは、自由に変えてよい（振る舞いと、使える操作は変えない）。

## 凡例

- **対象**：［ゲスト］ログインなし／［ログイン］ログイン済み／［持ち主］そのレシピの作者／［他人］他の人のレシピを見ている人／［管理者］運営者だけ
- 「 」内は、いま画面に出ている文言（トーンの参考。変えてよい）。
- **必須** ＝ 機能として、画面に必ず必要なもの。**条件つき** ＝ ある条件のときだけ出るもの（どんな条件かを書く）。
- 数や選択肢は、実装の値。

## 0. 全画面に共通すること

### 0.1 ページの最上部（全画面）
1. **アプリ名のリンク**（「れしぴょん」）→ ホーム `/`。
2. **ログインの欄**（常に、ここにある。独立した画面ではない）。状態は4つ：
   - **確認中**：「ログイン状態を確認しています…」
   - **未ログイン・メールアドレスの入力**：説明（「メールアドレスに、ログイン用の6桁のコードを送ります。パスワードは不要です。初めての方は、自動でアカウントが作られます。」）／メールアドレス欄／**「コードを送る」**（メールが空、またはボット判定が済むまで押せない）／同意の文（「ログインすると、利用規約と、プライバシーポリシー（外国にある事業者への、情報の送信を含む）に同意したものとみなします。」＝2つのリンク。新しいタブで開く）／**ボット判定（Turnstile）の表示**と、その失敗・読み込み中・未設定の文。
   - **未ログイン・コードの入力**（メール送信後）：通知（「◯◯ に6桁のコードを送りました（5分間有効）。届かないときは、迷惑メールのフォルダも確認してください。」）／**6桁のコード入力**（1つの入力欄を、6つの枠に見せる。貼り付け・自動入力・全角入力に対応。6桁そろうと、自動で送信）／**「ログインする」**／**「コードを再送（あとN秒）」**（待ち時間の間は無効。ボット判定が済むまで無効）／**「メールアドレスを変更」**。コードを間違えると、エラーの文が出て、入力欄が空になり、フォーカスが戻る。
   - **ログイン中**：「ログイン中」＋**表示名**＋**メールアドレス**＋**「ログアウト」**。
3. **エラー表示**（ログインの失敗など）：入力欄の下に、赤い文（読み上げ対応）。

## 2. 買い物メモ `/shopping`　［ゲストでも使える］

**ゲストでも、ログインでも使える**。データは、この端末（ブラウザ）に保存される。オフラインで動く。

### 2.1 画面の構成（上から）
1. 見出し「買い物メモ」
2. **ツールバー**：
   - **表示の切り替え**：「一覧」「店ごと」（どちらかが押された状態。選んだ状態は、端末に記憶）
   - **「売り場順」**（カテゴリの売り場の順に並べ替える）／**「逆回り」**（その逆順）。項目が2件未満のとき、並べ替え中は、押せない。
3. **追加フォーム**（常に出ている）
4. **「レシピから入れる」**　［ログイン］のみ
5. **在庫への換算の設定フォーム**　条件つき（購入確定で、設定が足りない項目があるとき）
6. **期限の確認**　条件つき（購入確定のとき、在庫に入る項目があるとき）
7. **「チェック済みを購入確定（N件）」**
8. **条件つきのメモ**（分岐）の欄
9. 状態の文：読み込み中「読み込んでいます…」／空「買うものはまだありません。」
10. **買う項目の一覧**（「一覧」表示か「店ごと」表示）

### 2.2 追加フォーム（必須）
| 欄 | 内容 |
|---|---|
| **買うもの** | 食材名。入力すると、**候補が出る**（食材のカタログ。ひらがな・カタカナ・全角半角を区別せず探す）。候補を選ぶと入力される。**候補にない名前も、そのまま入力できる**。例「卵、牛乳など」 |
| **数量** | 数。**分数に対応**（1/2、1と1/2、0.5）。入力した値が「= 0.5」のように、小数でも示される。単位によって、**押しボタン**が並ぶ（玉・株＝1/4・1/3・1/2・3/4、本＝1/3・1/2・2/3、個・丁＝1/2、カップ＝1/4・1/2・3/4、g＝+10・+50・+100・+200・+500、ml＝+50・+100・+200・+500。パック・袋・kg などには、ボタンなし） |
| **単位** | 自由入力。例「個、袋、gなど」 |
| **カテゴリ** | 選択。「未設定」＋15種：野菜・果物／豆腐・納豆・練り物・生麺／日用品／肉・肉加工品／魚・海産物／牛乳・乳製品／卵／調味料・乾物・缶詰・レトルト／冷凍食品・アイス／お菓子・製菓材料／米・麺・粉類／飲料・酒／惣菜・弁当／パン／その他。**食材名から、自動で選ばれる**。自分で選ぶと、自動では変わらない。 |
| **買う店** | 選択：「どこでも」／登録済みの店／**「＋ 新しい店を追加…」**（選ぶと、店の名前の入力欄と、**「この店を追加」「やめる」**が出る）。食材ごとに、**「いつも買う店」を覚えて、次から初期値にする**。 |
| **よく使う数量** | 食材によって出る**プリセットのボタン**（卵・牛乳・ホットケーキミックスなど。例：「10個入りパック」）。押した状態が分かる。押すと、数量・単位が入る。 |
| **「追加」** | ボタン。追加できると、欄が空に戻る。 |
| エラー | 欄の下に、赤い文。 |

### 2.3 一覧の1行（必須）
- **ドラッグのつまみ**（「⠿」）　［「一覧」表示のみ］ドラッグで並べ替え
- **チェックボックス**（チェックすると、購入確定の対象になる。「購入済み」の項目は、チェックを変えられない）
- **名前**＋**数量＋単位**＋（在庫への換算がある場合は）**「（換算した量）」の補足**。例「牛乳 1パック（1000ml）」
- **店のラベル**　［「一覧」表示のみ］
- **「購入済み」のラベル**
- **↑ ↓ ボタン**（1つずつ上下へ）　［「一覧」表示のみ］。先頭・末尾では、片方が無効
- **「編集」**／**「削除」**
- **チェック済み・購入済みの項目は、見た目が変わる**（一覧の中で、区別がつく）。

**編集**：行が、その場で編集フォームに変わる。欄は、**商品名・数量・単位・カテゴリ・買う店**。**「キャンセル」「保存」**。

### 2.4 表示の切り替え
- **「一覧」**：売り場順の1つのリスト。**ドラッグ・↑↓で並べ替えできる**。各行に、店のラベルが出る。
- **「店ごと」**：店ごとの**見出し**（「どこでも」を含む）の下に、項目が並ぶ。**並べ替えはなし**。追加で出るもの：
  - **「店の管理」**（開閉できる）：店の一覧。各店に、**「名前を変更」**（名前の入力＋「保存」「やめる」）と、**「削除」**（確認：「この店の項目は『どこでも』になります。」＋「削除する」「やめる」）。
  - **「今いる店」**（選択。店が1つ以上あるとき）：「すべての店」／各店。選ぶと、**その店と「どこでも」の項目だけ**を表示（買い物中に絞る）。

### 2.5 購入確定のフロー（必須）
1. 項目をチェックする。
2. **「チェック済みを購入確定（N件）」**を押す（チェックが0件のときは、押せない。処理中は、「購入確定中…」）。
3. **在庫に入る項目で、「在庫にどう入れるか」が未設定のものがあれば**、その項目について、**設定フォーム**が出る：「◯◯を在庫へ追加する方法」。購入した量（例：1パック）を、在庫の量にどう換算するか。
   - **候補から選ぶ**（プリセットのボタン）／**管理方法**（「だいたいで管理」「正確に管理」「有無だけ（量は追わない）」）／**在庫で使う単位**（個数・枚数・本数など／グラム／ミリリットル。食材によっては、単位が固定で、変えられない）／**「1◯◯あたりの数量」**／**表示単位**（個・枚・本など）／**「キャンセル」「設定を保存」**。
   - 設定するまで、購入確定は、進まない（「◯◯の在庫換算を設定してください」）。
4. **日用品**（カテゴリが「日用品」）は、在庫に入らない。購入済みになるだけ。
5. **在庫に入る項目があるときは、「期限を確認」の欄**が出る：説明（「入力は、任意です。入れなくても、そのまま購入確定できます。」）／**期限の目安の自動入力の設定**（下の 4.2）／**項目ごとの、期限の入力**（下の 11.3）／**「キャンセル」「購入確定」**。
6. 確定すると、項目は**「購入済み」**になる。ログイン中は、**在庫へ反映**される。
   - 通信できないとき：「購入は保存しました。在庫への反映は通信復旧後に再試行します」（あとで自動で再試行）。
   - **ゲストのとき**：購入は、この端末に保存される。**あとでログインすると**、「ゲスト購入を引き継ぎますか？ 未反映の購入が◯件あります。」＋**「今回は引き継がない」「このアカウントへ引き継ぐ」**が出る（結果の文：「ゲスト購入を引き継ぎ、在庫へ反映しました」ほか）。

### 2.6 在庫への同期の状態の文（買い物メモと在庫の、両方に出る）
- 「在庫を同期しています…」
- 「未反映の在庫があります」＋**「在庫同期を再試行」**
- 「N件の在庫を反映しました」

### 2.7 「レシピから入れる」　［ログイン］のみ
- ボタン**「レシピから入れる」**を押すと、パネルが開く。
- パネル：見出し「レシピから入れる」／説明（「自分のレシピから選べます。他の人のレシピから入れる機能は、今後対応する予定です。」）／**「レシピの名前で絞り込む」**入力／**自分のレシピの一覧**（読み込み中・「登録したレシピがまだありません。」・「合うレシピがありません。」）。
- レシピを選ぶと、**「買い物メモに入れる」パネル**（下の 6.4 と同じ内容。ただし、閉じる／入れた後は、このパネルに戻る）。「別のレシピを選ぶ」ボタン。

### 2.8 条件つきのメモ（分岐）（必須）
「これが売っていたら、こちらを買う。なければ、こちら」という**2つのまとまり**。
- **一覧**：条件ごとに、カードが並ぶ。
  - 見出し：**「◯◯ 数量 が売っていたら」**（条件になる材料＋どんな時か）＋店のラベル。
  - **2つの側**：**「そうなら」「そうでなければ」**（呼び名を付けたときは「そうなら（ハンバーグ）」）。各側に：項目の一覧（名前・数量・単位・店ラベル・**「削除」**）、空のとき「まだありません。」、**「◯◯にレシピから入れる」**（ログイン時）、**「◯◯に追加」**（開閉できる。追加フォームと同じ欄＋「この側に追加」）。
  - **「そうだった」**／**「ちがった」**：押すと、**選んだ側が、通常の項目になり**、もう一方と、条件のメモが消える（「そうだった」の場合、条件の材料も、通常の項目になる）。
  - **「条件つきのメモを削除」**（確認：「中のメモもすべて消えます。」＋「消す」「やめる」）。
  - 分岐の中の項目は、**メインの一覧には出ない**（チェック・購入確定の対象にならない）。
- **作る**：**「＋ 条件つきのメモを追加」**を押すと、フォームが開く：説明（「条件になる材料を入れて、どんな時かを書きます。」）／追加フォームと同じ欄（条件の材料）／**「どんな時に（材料が…）」**（初期値「売っていたら」）／**「そうなら（呼び名・省略可）」**／**「そうでなければ（呼び名・省略可）」**／**「条件つきのメモを作る」「やめる」**。

### 2.9 エラー・状態
- 保存に失敗：追加フォームの下の、赤い文。
- オフラインでも、買い物メモの操作は、すべて動く。

## 3. 在庫 `/inventory`　［ログイン］のみ

- **［ゲスト］**：「ログインすると在庫を確認できます。」だけ。
- **［確認中］**：「ログイン状態を確認しています…」。

### 3.0 デザインの方針（運営者が決定。2026-10-13）

在庫の画面は、**冷蔵庫の中を見ているような見た目**にする（案 A「断面のゾーン」＋案 B「残量つきの容器タイル」の組み合わせ）。**機能は、3.1 以降の一覧のとおり、すべて残す**（見た目だけを、変える）。

- **ゾーン**：**冷蔵室**／**ドア**（有無だけで管理している食材＝塩・醤油・油など）／**野菜室**／**冷凍室**／**机の上**（常温。冷蔵庫の外）。
- **食材の見え方**：ゾーンの中に、**容器のタイル**（名前・量・期限の近さ。**量を追う食材は、中身の量が、水位のように見える**）。**期限が近い・切れたものは、一目で分かる**。有無だけの食材は、「あり／なし」（数字は出さない）。
- **食材を押すと、詳細が、パネル（またはボトムシート）で開く**。いまの「調整」「単位を変える」「名前を変更」「削除」「管理方法の切り替え」と、**ロットごとの数量・期限の編集**は、すべて、**このパネルの中**に集める（冷蔵庫の絵の中に、フォームを置かない）。ロットの一覧（追加した日・保存方法・期限・量）も、パネルの中。
- **新規登録は、ボタンから開く**（パネル／ボトムシート。画面の常設のフォームは、やめる）。**連続して登録できる**：「在庫に追加」「ある（量は追わない）」を押しても、**閉じない**（入力欄は、空に戻る。完了は、ボタンの完了の表示で伝える）。**パネルの外を押すと、閉じる**。ただし、**閉じるボタンと Esc キーでも、閉じられる**こと（キーボード・読み上げの人のため）。
- **ゾーンの決め方（データ）**：保存方法は、**ロットごと**にある（任意）。ロットに保存方法が未設定のときは、**食材のカタログの、初期の保存方法**を使う。野菜室は、カタログの売り場（野菜・果物）から。有無だけの食材は、ドア。**同じ食材のロットが、別のゾーンにまたがるとき**（例：牛乳が、冷蔵と冷凍）：**ゾーンごとに、タイルを出す**（そのゾーンのロットの量だけ）。
- **オフラインのとき**：保存済みの在庫を、読み取り専用で見せる（パネルの中の、書き換えの操作は、無効）。「通信できないため、保存済みの在庫を表示しています。最終更新：◯◯」の知らせは、残す。
- **空の状態**：空の冷蔵庫（れしぽよが、いる）。**「在庫はまだありません。」**の代わりに、登録への誘導。
- **ゲスト**：「ログインすると在庫を確認できます。」（冷蔵庫の外観は、出さなくてよい）。

**デザイン側に、決めてほしいこと**
1. 各ゾーンの**絵の表現**（棚・引き出し・ドアポケット・机）と、**タイルの大きさ**（スマホ：1行に何個か）。食材が多いとき（50個以上）の、**見渡しやすさ**と、**ゾーンの中のスクロール**。
2. **容器タイルの、量の表し方**（水位・色の濃さ・目盛り）。「約」（だいたいで管理）と、正確の区別。**個数・枚数の食材**（卵6個、など）の表し方。
3. **期限の近さ**の表し方（色だけに頼らない。例：印・枠・文字）。期限切れも。
4. **パネル／ボトムシート**の構成：上から、食材名・量・（有無だけは、あり／なしの切り替え）・主な操作・ロットの一覧・ほかの操作（単位・名前・管理方法・削除）。**7種類のフォーム（3.3）が、どう切り替わるか**。
5. **新規登録のパネル**：項目（食材名・単位・管理方法・数量・よく使う数量・期限・保存方法）の並べ方。**連続登録のときの、完了の見せ方**（フォームは、閉じない）。
6. **机の上**（常温）の表現。
7. 食材が**ロットを複数持つ**ときの、タイルとパネルでの見せ方。
8. **ゾーンの中の、並び順**（いまは、食材名の順。期限順などを、提案してよい）。
9. 冷蔵庫の見た目の、**キーボード・読み上げ**での扱い（中身は、リストとして読めること）。

### 3.1 画面の構成（上から）
1. 在庫への同期の状態の文（2.6 と同じ）／ゲスト購入の引き継ぎ（2.5 の最後）
2. **期限の目安の自動入力の設定**（4.2）
3. **「在庫に直接追加」フォーム**（4.1）
4. **在庫の一覧**（見出し「在庫」＋**「更新」**ボタン）

### 3.2 在庫の一覧（必須）
- **並び順**：食材名の順。（期限順・カテゴリ順・保存方法ごとなどの並び替え・絞り込み・検索は、**ない**。デザインで提案してよいが、データはある：ロットごとに保存方法・期限がある。）
- **状態**：「在庫を読み込んでいます…」／「在庫はまだありません。」／エラー（赤い文）／**オフライン**：「通信できないため、保存済みの在庫を表示しています。 最終更新：◯◯」（この間、**書き換える操作のボタンは、無効または非表示**＝調整・単位・名前・削除・数量・期限・管理方法）。

### 3.3 食材1つ（必須）
**見出し行**：
- **名前**（自分で付けた呼び名があれば、呼び名＋「（元の名前）」）
- **量**：
  - 数量を追う食材：「約 3個」「1/2玉」「250g」（**「約」＝だいたいで管理**。「約」なし＝正確に管理）。個数・枚数・本数は**分数**、g・ml は小数。
  - **有無だけの食材**（塩・醤油など）：**「あり」／「なし」**（数字は出さない）。
- **ボタン**（食材の種類によって変わる）：
  | ボタン | 出る条件 |
  |---|---|
  | **「なくなった」／「ある」** | 有無だけの食材。押すと、あり⇔なし |
  | **「調整」** | 数量を追う食材。押すと、調整フォーム |
  | **「量を追う管理にする」** | 有無だけの食材（量の入力＋管理方法を聞く） |
  | **「有無だけにする」** | 数量を追う食材 |
  | **「単位を変える」** | 数量を追う食材 |
  | **「名前を変更」** | すべて |
  | **「削除」** | すべて |

**ロット**（その食材の、買った・追加した単位。食材の下に並ぶ）：
- 「**10/3に追加**」
- **保存方法のバッジ**：「常温」「冷蔵」「冷凍」（設定があるとき）
- **期限**：「消費期限 10/10」「賞味期限 約 10/14」（**「約」＝自動の目安**）／「期限なし」／（期限の設定なしは、表示なし）
- **量**（数量を追う食材。「約」付きの場合あり）
- **「数量」**ボタン（そのロットの量を直接直す）／**「期限」**ボタン（期限・保存方法を直す）
- 有無だけの食材は、ロットの量を出さない。

**フォーム（押したボタンに応じて、その場（その食材の下）に開く）**：
1. **調整**：「◯◯の調整数量」（数量入力：分数・単位ごとの押しボタン）／ロットが2つ以上のとき、**「ロットを指定して減らす」**（チェック。ロットごとに、減らす量を入力）／**「キャンセル」「減らす」「増やす」**（量が0のとき、「減らす」は無効）。
2. **ロットの数量を直す**：数量入力＋**「キャンセル」「この数量にする」**。
3. **ロットの期限を直す**：期限の入力（11.3）＋**「この食材の初期値にする（期限の種類・保存方法）」**（チェック）＋**「キャンセル」「保存」**。
4. **単位を変える**：「◯◯の新しい単位（いまは△△）」（選択：その食材に合う単位。個数の呼び名＝本・玉・株・枚・個、g、ml など）／**ロットごとの量**（「換算した目安が入っています。違えば直してください」。ロットごとに、数量入力）／**「キャンセル」「この単位にする」**。
5. **名前を変更**：「在庫の一覧に出す名前（◯◯のまま、レシピとの照合に使います）」（入力。50文字まで）／**「キャンセル」「この名前にする」**（空にすると「元の名前に戻す」）。
6. **削除の確認**：「「◯◯」を在庫から削除します。ロットと履歴も消えます。よろしいですか。」＋**「やめる」「削除する」**。
7. **量を追う管理にする**（有無だけ → 数量）：「◯◯のいまの量」（数量入力）／**管理方法**（「だいたいで管理」「正確に管理」）／**「キャンセル」「この量で管理する」**。

## 6. レシピの参照 `/recipes/◯◯`　［ログイン］

**ログインが必要**（［ゲスト］は、レシピを見られない。開くと、エラーの画面になる）。3つの見え方がある。

### 6.1 見られないとき・存在しないとき（区別せず、同じ画面）
- 見出し「レシピが見つかりません」／説明（「限定公開のレシピは、作者から教えてもらったパスフレーズを入力すると、見られます。」）／**「パスフレーズ」入力**（ひらがなの単語をつなげたもの）／**「開く」**。

### 6.2 レシピの本体（共通。必須）
- **レシピ名**（大見出し）／**「N人分」**
- **材料**：リスト。**グループ**（見出し付き。入れ子）／材料名＋**分量**（原文のまま。例「大さじ1と1/2」「適量」）。材料名の中に、**他のレシピへのリンク**があると、**押せる**（→ 6.5）。**リンク先の材料が、その材料の下に、その場で開く**（「◯◯の材料を開く／閉じる」。2段目まで最初から開いている。輪になっているときは「（上で表示済み）」）。
- **下準備**（あるとき）：箇条書き
- **作り方**（あるとき）：番号つきリスト
- **引用元**（あるとき）：URL（http・https はリンク、それ以外は文字）
- **メモ**（あるとき）
- 本文の中の **`[[ラベル]]`** は、リンク先の名前の**押せるボタン**（下線つき）になる。リンク先が見られないとき「（見つからないレシピ）」。

### 6.3 ［持ち主］の画面（本体の下に続く）
1. **［限定公開のレシピのみ］「限定公開のパスフレーズ」**の欄：説明／パスフレーズ（表示）／**「コピー」**／**「作り直す」**→確認（「作り直すと、これまでに開けた人も、新しいパスフレーズを入れないと、見られなくなります。」＋**「本当に作り直す」「やめる」**）。
2. **「買い物メモに入れる」**（6.4）
3. **「作った」**（6.6）
4. **「編集」**（→ 7）
5. **「削除」**→ 確認（「このレシピを削除します。元に戻せません。」＋「削除する」「キャンセル」）→ 削除後、一覧へ。
6. **「レシピ一覧へ」**

### 6.4 「買い物メモに入れる」（［持ち主］［他人］の両方）
- 最初は、ボタン**「買い物メモに入れる」**だけ。押すと、パネルが開く。
- 説明：「在庫と比べて、足りないものを選んでいます。人数による量の調整は、していません（レシピの量のままです）。」
- **「メモに同じものがあるとき」**（選択：「多い方に合わせる」「合算する」「追加しない」）。
- **材料の一覧**（グループの見出し付き）。各行：**チェックボックス**（初期：足りないもの・在庫がないものがチェック、足りているものは外れる。リンク先のレシピの材料は、初期は外れる）／材料名＋**分量**／**在庫の状態**（「足りている」「足りている（在庫あり）」「在庫が0」「在庫なし」「在庫の情報なし」「◯◯の在庫で足りています」「（◯◯の在庫があります）」）／同じ材料が複数行あれば「N行をまとめています（大さじ1 ＋ 少し）」／メモに同じものがあれば「メモに「卵 6個」あり → 10個に更新」ほか／在庫になく、有無だけで管理できる材料には、**「ある（在庫に登録）」**ボタン。

## 7. レシピのエディタ `/recipes/new`・`/recipes/◯◯/edit`　［ログイン］

- ［ゲスト］（新規）：「レシピを登録するにはログインしてください。」
- 上部の小見出し：「レシピを登録」／「レシピを編集」。

### 7.1 構成（上から）
1. **レシピ名**：クリックして編集する見出し（「無題のレシピ」。Enter・Esc・フォーカスを外すと確定。空のまま保存しようとすると、メッセージを出して、ここに移る）。
2. **「何人分」**（数）／**「引用元URL（任意）」**
3. **表示の切り替え**：**「入力」「プレビュー」**（タブ。幅が広い画面（約900px以上）では、**左に入力・右にプレビューを、同時に**出す。狭い画面では、タブで切り替える）。
4. **入力欄（1つ）**＋補助。
5. **プレビュー**（「保存前の確認」）
6. **公開範囲**
7. **「レシピを保存」**
8. エラーの文／保存した文（「レシピを保存しました。」）

### 7.2 入力欄（必須）
- **入力欄は1つ**。**見出し**（`＜材料＞`・`＜下準備＞`・`＜作り方＞`・`＜メモ＞`。`<>`・`【】`・`■` などでも可）で区切って書く。見出しがなければ、空行で区切った文章から、材料と作り方を判別する。
- 新規のとき：**「新規登録で、見出しを最初から入れる」**（チェック。端末に記憶）。
- 説明文（「＜材料＞＜下準備＞＜作り方＞＜メモ＞の見出しで区切ります。…」）。
- **補完メニュー**（入力中に出る）：
  - 出る内容：**見出し**（`＜` を打つと）／**材料名**（カタログの食材。ひらがな・カタカナで）／**作り方・下準備の中で、材料に書いた名前とグループ名**／**記号**（「ほし」→☆★、「まる」「しかく」「さんかく」「こめ」→※、「やじるし」「おんぷ」「はーと」）／**`[[` で、リンクするレシピ**／**`[[@` で、他のユーザー→そのユーザーの公開レシピ**。
  - 見え方：**PC＝カーソルの真下に、縦の一覧**（日本語の変換候補の窓と重ならないよう、上に出ることもある）／**スマホ＝キーボードのすぐ上に、横にスクロールできる帯**。
  - 操作：↑↓（変換中は Alt＋↑↓）で選ぶ／Tab（選んだあとは Enter）で決定／Esc で閉じる／タップで決定。ヒントの文（「↑↓で選び、Tab で決定（Esc で閉じる）」）が出る。
  - 状態の文（メニューの中）：「ユーザーを探しています…」「全体公開のレシピがある人が、見つかりません。…」「レシピを読み込んでいます…」「公開されているレシピが、見つかりません。」
- **番号・中黒の自動入力**：「1. 」の行で Enter → 次の番号。「・」の行で Enter → 次の中黒。印だけの行で Enter → 印が消える。
- **元に戻す／やり直す**（Ctrl/Cmd＋Z、Shift＋Z、Ctrl＋Y）。
- **「現在の位置にレシピをリンク」**ボタン（入力欄の下）→ **レシピを選ぶ一覧**が開く：「自分のレシピ」「他の人のレシピ」の切り替え／**「レシピを探す」「レシピの名前で探す」**／（他の人のレシピ）ユーザーを探す（「表示名か、ハンドルで探す」）→ 選ぶと「◯◯（@handle）のレシピ」＋**「ユーザーを選び直す」**＋レシピの名前で絞る／**「閉じる」**／状態の文（読み込み中・なし・見つからない・読み込めなかった）。

### 7.3 プレビュー（「保存前の確認」。必須）
入力から、**自動で作られる**。**手で直せる**。
- **材料**：リスト。
  - **グループ**：グループ名（**編集できる**）＋「（推定グループ）」の印＋**「グループを削除」**。
  - **材料の行**：**材料名**（編集）／**分量**（編集。「分量なし」）／**グループの選択**（「グループ外」＋各グループ。移動）／**「削除」**。
  - **手直しした行**：**「手直し済み」**の印＋**「元に戻す」**（本文から読み直した状態に戻す）。本文を書き換えても、手直しした内容は、守られる。
  - **リンク**：材料名の中の `[[…]]` は、押せる（6.5 のシート）。
- **「材料を追加」**（材料名＋分量の入力＋ボタン。Enter でも追加）／**「グループを追加」**（グループ名＋ボタン）。
- **下準備**（リスト）／**作り方**（番号つきリスト）／**メモ**（あるとき）。
- **「分類できなかった文章」**（あるとき。「見出し（＜材料＞＜作り方＞など）を付けると、保存されます。いまは、保存されません。」）。
- **人数**の見出し（材料・作り方の見出しに「2人分」などがあると、人数の欄に入る）。

### 7.4 公開範囲（必須）
- **3つの選択（ラジオ）**：**「非公開（自分だけ）」**（初期）／**「限定公開（ログインした人のうち、パスフレーズを知っている人だけ）」**／**「全体公開（ログインした人なら、誰でも見られる）」**。
- **引用元URLがあるレシピは、公開できない**（その旨の文。公開の選択は無効）。
- 限定公開を選ぶと：パスフレーズの説明（「保存すると自動で作られ、レシピの画面で確認できます。…漏れたと思ったら、作り直してください。」）。
- 公開を選ぶと：**同意の文**（「自分で考えた、または自分の言葉で書いたレシピだけを、公開してください。公開する前に、書かれた文章が、公開してよい内容かを、自動で確認します（利用規約）。公開されるのは、レシピと、あなたの表示名・ハンドルだけです（メールアドレスは、見えません）。表示名・ハンドルは、プロフィールで変えられます。」＝利用規約・プロフィールへのリンクつき）。
- 保存のとき、公開する場合は、**文章の自動確認**がある。止められると、**その欄を示す文**が出る（止めた語は見せない）。

### 7.5 保存
- **「レシピを保存」**（処理中・完了・失敗）。
- 検証の文：「レシピ名を入力してください。」「材料のないグループがあります。材料を移すか、グループを削除してください。」、入力の上限（レシピ名100文字、材料100件、下準備・作り方は各50件・1件1,000文字、メモ3,000文字、全体12,000文字、1人300レシピまで）。
- 新規は保存後、レシピの参照へ移る。

## 8. プロフィール `/profile`　［ログイン］

1. **「プロフィール」**：説明（「公開されるのは、表示名とハンドルだけです。メールアドレスは、公開されません。」）／**表示名**（入力。文字数の制限と「@ は使えません」）／**ハンドル**（入力。「半角の英小文字・数字・_・- の3〜20文字。ほかの人と重ならない名前にしてください。あとから変えられます。」）／**「保存する」**／各欄の下に、エラーの赤い文／保存した文「保存しました。」。表示名・ハンドルは、**変えるとき、不適切な語がないか自動で確認される**。
2. **「アカウントの削除」**：説明（「アカウントと、保存した情報を削除します。削除は、すぐに行われ、取り消せません。」）／**「アカウントを削除する」**→ 確認：削除されるもの・残るものの一覧／**ハンドルの入力**（「確認のため、ハンドル（◯◯）を入力してください」）／**「確認のメールを送る」**（ハンドルが一致するまで無効）／**「やめる」**。送ったあと：確認のメールの案内（メールのリンクを開くと、すぐ削除される）。
- 削除したあと：**`/account-deleted`**「アカウントを削除しました」＋「アカウントと、保存した情報を削除しました。ご利用ありがとうございました。」＋**「トップへ」**（端末のデータも消す）。

## 9. 利用規約・プライバシーポリシー `/terms`・`/privacy`

- **長い文章のページ**（ログインなしでも見られる）。見出し（「れしぴょん 利用規約」）＋**条ごとの見出し**＋本文。ログイン画面の同意の文からリンクされる。

## 10. 停止の画面（アカウントが停止されているとき。全画面がこの画面になる）

- **一時停止**：「アカウントが停止されています」＋理由の説明＋**「申し立ての内容」**（入力）＋**「申し立てを送る」**＋送信後の文（「申し立てを送りました。管理者の確認をお待ちください。」）。申し立ては何度でもできる。
- **永久停止**：「このアカウントは、利用できません」＋説明。

## 11. 共有の部品の、機能

### 11.1 食材名の入力（候補つき）
- 入力すると、食材のカタログから**候補の一覧**が出る（ひらがな・カタカナ・全角半角を区別しない。完全一致→前方一致→部分一致の順）。↑↓で選び、Enter で決定。**一致しているときは、候補を出さない**。**候補にない名前も、そのまま使える**。

### 11.2 数量の入力
- 分数対応（1/2、1と1/2、1½、0.5）。下に「= 0.5」のように、読み取った値を出す。
- **単位に応じた押しボタン**（2.2 の表）。「set」＝値を置き換える／「add」＝足す。

### 11.3 期限の入力（登録・購入確定・ロットの編集で共通。すべて任意）
- **期限**（日付）＋**「今日 10/13（月）」**（今日の日付を小さく表示）。
- **期限の種類**：「指定しない」「消費期限」「賞味期限」「期限なし」。
- **保存方法**：「指定しない」「常温」「冷蔵」「冷凍」。
- **クイック入力のボタン**：「今日」「明日」「+3日」「+1週間」（押すと、期限が入る）／**「期限を消す」**。
- **自動の目安**が入っているとき：「目安の日付（約）です。パックや袋の表示がある場合は、その日付を入れてください。」（目安を、自分で直すと、「入力」扱いになる）。

### 11.4 いま、画面にある「状態の見せ方」（一貫していないもの）
- 読み込み中：文字だけ（「読み込んでいます…」）。
- 空：文字だけ。
- エラー：赤い文（読み上げ対応）。
- 成功：文字、または、ボタンの完了表示。
- オフライン：文字だけ（在庫）。

## 12. 管理者の画面 `/admin/*`　［管理者］のみ（一般の導線には出ない）

最小限の整理でよい（見た目の優先度は低い）。ただし、機能は、そろえる。

- **共通**：管理者のメニュー（**「管理の入口」「通報」「ユーザー名の通報」「停止への申し立て」**の4つ）。
- **管理の入口**：3種類の未対応の件数（通報・ユーザー名の通報・停止への申し立て。各々、一覧へのリンク）＋**ユーザーの検索・停止へのリンク**（「探して、停止・永久停止・解除をする」）。
- **通報の一覧（未対応）**：各通報に、レシピ名（「（削除済み）」の表示）／理由（「権利を侵害している」「不適切な内容」「その他」「自動検知（公開のときの判定で、怪しいとされた）」）／詳細／作者（名前・ハンドル）／**「レシピを見る」**（その場に読み込んで表示）／**「投稿者を停止する（ユーザーの画面へ）」**／**対応**：**「非公開にする」「削除する」（確認：「本当に削除する」「やめる」）「対応しない（却下）」**。**自動検知**（通報者なし）も、ここに載る。**下に「対応済みの通報」の履歴**（新しい順・直近100件。何をしたか・いつ）。
- **ユーザー名の通報（未対応）**：通報された名前・ハンドル・いまの名前（退会済みの表示）／**「名前を初期値に戻す」（確認：「本当に戻す」「やめる」）／「却下する」／「停止する」へのリンク**。**下に「対応済み」の履歴**。
- **停止への申し立て（未対応）**：申し立てたユーザーのメールアドレス・日時・申し立ての内容・停止の理由・**AI の見立て**（「正当な申し立て」「正当ではない」「判断できない」「AI は判定していません」）／**「停止を解除する」「永久停止にする」（確認：「本当に永久停止にする」「やめる」）「申し立てを退ける（停止は続く）」**。**下に「対応済み」の履歴**。
- **ユーザーの検索・停止**（`/admin/users`）：**「表示名・ハンドルで探す」**入力＋**「探す」**（空欄なら、新しく登録した順に20件）／結果の各行：名前・ハンドル・状態（停止中／永久停止中）・「登録日・公開のレシピN件・違反N回・通報されたN件」・停止の理由／**「停止する…」**→ 理由の入力（必須）＋「このユーザーの公開のレシピを、すべて非公開にする」（チェック。初期はオン）＋**「停止する」**／**「永久停止にする」**（確認：「本当に永久停止にする」「やめる」）／**「停止を解除する」「永久停止を解除する」**（確認：「本当に解除する」「やめる」）。管理者のアカウントは、停止できない。

## 13. 「ない」機能（誤って、デザインに入れないための一覧）

- **通知**（プッシュ・メール）／**ダークモード**／**設定の画面**（期限の目安の設定は、在庫と購入確定の画面にある）
- ユーザー間の**チャット・DM**
