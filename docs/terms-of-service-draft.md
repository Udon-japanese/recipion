# 利用規約についてのメモ（運営者向け）

規約の本文は、コード内（`src/features/legal/domain/terms-content.ts`）が正本で、`/terms` のページに表示される。
このファイルは、運営者向けのメモ（公開されない）。

## 決まっていること
- 連絡先：contact@recipion.app（Cloudflare Email Routing で転送。届くことを確認済み）
- 方針：確実に言えることだけを、短く書く。法的に聞こえるが、意味を理解していない言葉は、使わない。
- 専門家の確認は、受けていない。サービスが大きくなったときや、公開機能を広げるときに、相談する。

## 残っていること
1. 運営者の名前の出し方（「れしぴょん運営者」だけでよいか、は、専門家に聞きたい点）。
2. 退会（アカウントの削除）：機能がない。規約に書くなら、機能が先に必要。
3. プライバシーポリシー（別の文書）。事実として言えること：
   - メールアドレスは、ログイン用のコードを送るためと、利用者を区別するために使う。
   - コードのメールは、メール送信のサービス（Resend）を通して送る。
   - ログインの画面の不正利用を防ぐために、Cloudflare Turnstile を使う。
   - データは、Cloudflare と Neon（データベース）に保存している。
   - 他の利用者には、公開を選んだレシピと、表示名・ハンドルだけが見える（メールアドレスは見えない）。
4. 準拠法・裁判所の指定、子どもの利用、有料機能：書いていない。
5. 公開ボタンの上の同意の文面（P2b）。
